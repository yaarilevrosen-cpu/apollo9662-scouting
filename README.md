# סקאוטינג ביובאז – אפולו 9662

אפליקציית הסקאוטינג של קבוצת אפולו 9662 לעונת ביובאז: איסוף נתונים מהיציע, סטטיסטיקות חיות לכל קבוצה, תחזית משחקים, בחירת ברית ותפקיד מנהל.

## מבנה

- `app/index.html` – האפליקציה, קובץ אחד. גרסה 01 של המאגר (מקבילה לגרסה 5 שרצה כארטיפקט).
- `server/` – השרת על המחשב הביתי (בתכנון). כאן רק קובץ הגדרות לדוגמה.
- `docs/data-contract.md` – איך נתוני הסקאוטינג עוברים לאפליקציית ניהול הפיט.

## כללי בטיחות – המאגר ציבורי

1. אין סודות: בלי סיסמאות, אסימונים או כתובת השרת הביתי. הם נמצאים ב־`server/config.local.json`, שמוחרג מהמאגר.
2. אין נתונים: בלי רשומות סקאוטינג, בלי ייצוא ובלי גיבויים.
3. נתוני ההדגמה בקוד נוצרים בזמן ריצה, עם מספרי קבוצות דמיוניים (90001 ומעלה) ושמות מומצאים.
4. לפני כל דחיפה: לבדוק שאין בה את 1 ו־2.

## מקור האמת

המאגר הזה הוא מקור האמת לקוד. בדרייב, בתיקייה "04 סקאוטינג / קוד", יש רק מסמך הפניה לכאן.
